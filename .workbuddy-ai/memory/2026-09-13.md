## 第 9 步验收第 7 项：聊天发送能停驾驶（提交 1962e7d）

**关键代码**（`App.tsx:574-596` 的 `sendChat`）：
```js
if (!value || streaming) return;  // 上一轮流式还没结束就拦下，不进 sendChat
if (敏感字段正则命中) { setChatNote(...); focusBrowser(); return; }
```
