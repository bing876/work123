## 4. 验收 ③ 的重点证据：切换期时间线（逐条时间戳）

一条 8 步的浏览器任务（`打开 http://127.0.0.1:8899/page-a 把整页读完，最后给我一份 SPAN-2B-PA 结论`），

**四路独立证据（缺一不可）**：

1. **服务端循环步数** `0 → 1 → 3 → 4`（人在 B 的三次采样里还在涨）；
2. **主进程司机状态** 三次采样全是 `phase="running"`、`blocked=false` —— 桌面这一路从没被拆掉或暂停；
3. **模型调用** `llmCalls 3 → 5 → 6`，相邻两次调用最大间隔 **2528ms**（没有出现被挂起的长空档）；
4. **页本身** `timeOrigin` 不变（**没被重载**）+ 页内 JS 计数器在后台从 0 涨到 68 + `wcId=3` 没被重建。

**为什么「服务端步数涨」就等于「桌面没断」**：这条链路是**主进程拉**的 ——
`main.ts` 的 `runToolLoop()` 负责 `/agent/loop/start` → 执行工具 → `/agent/loop/next` 喂回执 → 下一步。
**没有主进程在拉，服务端一步都走不了**。所以第 1 条与第 2 条是同一件事的两面。
（这一条也是本轮踩的坑之一：一开始拿主进程司机的 `step` 当参照，而它在这条链路里**恒为 0**，见 §6。）

## 6. 本轮抓出并修掉的问题（2 个真 bug + 1 次自我回退 + 4 处取证口径）

### bug #1 —— `.sidebar` 内容超出被 `body{overflow:hidden}` 切掉，「＋ 添加」点不到

**症状**：脚本报 `FAIL 项目 A 里「＋ 添加」也点得到`，参数 `asAgentId=None`，随后 `IndexError`。
**根因**：`.sidebar` 是 `.app` 的 flex 子项，**flex 子项的 `min-height:auto` 不肯缩到内容以下**，
760px 高的窗口里左栏内容超出后，超出部分被 `body` 的 `overflow:hidden` 直接切掉 —— 按钮在 DOM 里、但点不到。
**修法**：给 `.sidebar` 加 `overflow-y: auto`（内容装得下时毫无区别，装不下时每个入口都够得着）。

### bug #2 —— `.agentList` 被挤成 0 高，整颗「＋ 添加」按钮被裁掉（同类，更隐蔽）

**症状**：第一轮修完后默认项目过了，项目 A 又失败：命中自检显示 `elementFromPoint` 落到 `.sidebar` 上，
且 `agentList: {"sh": 98, "ch": 0}` —— **列表高 98、可视高 0**。
**根因**：`.agentList` 自己就是 `overflow-y:auto`，按规范这种 flex 子项的 `min-height:auto` **解析成 0**，
于是左栏一超高它就被压成 0 高：它自身"能滚"，但整颗按钮被裁在盒子外。
**修法**：`.agentList { flex-shrink: 0 }` —— 明确不参与收缩，要滚让左栏滚，列表保持自然高度。

> **教训（写进 `scripts/verify/README.md` 了）**：`overflow:auto` 的 flex 子项在空间不够时会缩到 0。
> 验「按钮点得到」**必须用 `elementFromPoint` 做命中自检**，只看 `querySelector` 找得到是没用的 ——
> 这两个 bug 都是「DOM 里有、用户点不到」，比崩溃更难发现。

### 一次自我回退 —— 中途加的「切换后自动收起项目列表」被我撤掉了

第三轮我在 `switchProject / createProject` 成功后加了 `setProjectsOpen(false)`（想少占左栏高度）。
结果把 `.projectBox__row` 从 DOM 里拿掉了，测试读不到项目行 → 报「界面上建出了项目 A」失败。
**决定回退**：真正的根因修复只有 bug #2 那一行 CSS；自动收起属于我**顺手加的行为变更**，
既不是用户要求的、又让项目行在切换后不可见，**不划算，撤掉**。（保持最小改动。）

## 7. 已知限制 / 需要确认的取舍点

1. **项目入口是最简版**：只有「看得见全部项目 / 新建 / 点一下切换」。下拉动效、双击切换、全屏小圆圈等
   **正式交互按边界要求没做**，等独立 UI 阶段。
2. **左栏现在可滚动**：这是修 bug #1 引入的行为（760px 窗口下内容超出时可滚）。不是视觉设计，
   但会让左栏出现滚动条 —— 若要改成「项目入口折叠 / 智能体列表独立滚动」等更讲究的排布，属 UI 阶段的活。
3. **「＋ 添加」的推断口径**：取当前项目里**第一个** `canCreateAgents=true` 的。
   目前每个项目恰好一个（默认项目=小助、新建项目=母鸡），所以"第一个"和"唯一一个"等价；
   若将来一个项目出现多个可建智能体的智能体，需要再定口径（先到先得 / 指定）。
4. **没做母鸡调度**、**没改浏览器分区规则**、**没做视觉美化** —— 均按边界要求。
5. **本段未推送**：按指令「完成后汇报、停下等待下一步指令」，改动**只在本机工作区**，未 commit、未 push。
